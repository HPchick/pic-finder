# PIC FINDER 项目文档

PIC FINDER 是面向画师的参考图检索与归档工具。本文档是其设计文档的总入口。

- 软件名称：PIC FINDER
- 运行平台：Windows 10 与 Windows 11，64 位
- 当前版本：0.1.7
- 文档版本：v0.21
- 文档状态：源码已完成缺陷回归；发行包的界面验证仍待排查。

## 快速开始

当前仓库提供源码。新克隆的仓库请按下方说明运行。
0.1.7 的便携包和安装程序仅保存在本机，尚未作为正式发行版发布。
启动自检已通过，但界面冒烟测试返回退出码 1。
详情见[打包记录](release-0.1.7.md)。

| 产物 | 用法 | 适合谁 |
|---|---|---|
| `PIC-FINDER-Setup-0.1.7.exe` | 本地待验证的安装程序 | 安装、升级与卸载测试 |
| `PIC-FINDER-0.1.7.zip` | 本地待验证的便携包 | 界面退出问题排查 |

两个产物都不需要管理员权限。安装程序固定按当前用户安装，默认装在用户目录。

从源码跑：

```powershell
# 在项目根目录运行，要求 Python 3.11 或更新版本。
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
$env:PYTHONPATH = Join-Path $PWD "src"
python -m picfinder              # 启动界面，首次启动会问数据放在哪里
python -m picfinder --check      # 只做启动自检
python tests\run_tests.py        # 离线测试，报告写入 tests\test-report.txt
python tests\run_tests.py --network  # 可选：真实接口测试
```

从源码重新打包：

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1 -Python C:\PYthon313\python.exe -Zip
powershell -ExecutionPolicy Bypass -File installer\verify.ps1
powershell -ExecutionPolicy Bypass -File installer\make-installer.ps1
```

打包需要提权执行（PyInstaller 要用命名管道）。**不要加 `-Clean`**，见 [work/readme.md](work/readme.md)。

打包与安装的完整说明见 [installer/readme.md](installer/readme.md)。

现在可以做的事：在检索页选一个类别，输入「站姿 侧视 回眸」这类中文描述，
按回车翻译出标签，勾选来源，点「检索」即可看到跨站汇总的缩略图图墙。
勾选想要的图，点「下载所选」，文件会按规则命名并归档到图库目录，
同时写入索引数据库。双击卡片会打开程序内预览。原帖地址显示在预览窗口中。

首次启动会弹出向导确认数据目录，路径右侧可以直接点「选择文件夹」换位置，
窗口里会实时显示图库会建在哪里。这一步只出现一次。

代码结构与开发期注意事项见 [work/readme.md](work/readme.md)。

## 软件定位

这个软件解决三个问题：把中文描述翻译成图库标签、跨多个图库检索参考图、把下载的图自动归档。

它的核心能力是翻译。图库只认英文或日文标签，画师想不出该搜什么词。这个软件负责把中文意象翻译成标签，并把翻译结果展示给用户修改。

## 目标用户

主用户是一位画师朋友。她不是技术人员，不装环境、不改配置、不读日志。

主用户的电脑为拯救者 Y7000P，配置 32 GB 内存、1 TB 硬盘与 5060 显卡。本地大语言模型推理不做，理由是成本与复杂度。本地图像标注属于后续计划，目前尚未接入。人工智慧能力优先通过网络接口提供，接口不可用时软件仍须保持可用。

开发者为次用户。开发者是计算机专业本科生，有 C 与 Python 基础，未接触过其他编程语言。

主用户已完成两轮访谈，需求依据见 [docs/interviews.md](docs/interviews.md)。尚未访谈的是界面操作习惯与参考图流转方式，这是当前最大的需求风险。

## 两种使用模式

软件有两个入口，共用同一套图片元数据与本地图库。

**文字搜图**（第一期实现）：输入中文描述，软件翻译成标签并展示，用户确认后跨站检索，勾选下载并归档。

**以图找源**（第二期实现）：丢入一张图片，软件并发查询多个以图搜图服务，汇总原帖链接、画师与相似图。

两个模式的连接点在于互相喂养。搜到的图可以一键查出处，查到的出处可以回写图库。
