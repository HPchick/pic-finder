# 工作区目录说明

## 唯一仓库入口

本项目的工作区文件统一放在 `picfinder/` 中。
该目录包含 `.git`，也是后续提交和上传的唯一入口。
原来的 `pic-finder/` 工作副本已迁入这里。

源码保持原有布局，避免改变运行和构建路径。
根目录保留代码审查报告与上传准备记录，便于查阅。

## Git 上传范围

在 `picfinder/` 根目录执行 Git 命令即可。
源码、正式词典、测试和文档参与版本控制。
`.local-work/` 中的副本、缓存和操作记录不会参与提交。

旧审查副本中的 Git 元数据也位于忽略目录内。
它们只保留为本地历史材料，不作为子模块或独立上传入口。
无需进入这些副本运行 Git 命令。

可先检查实际待提交内容：

```powershell
git status --short
git ls-files --others --exclude-standard
```

本次整理没有执行提交或推送。

## 本地材料的使用边界

`scripts/` 中的脚本记录已完成的审查操作。
脚本和历史清单保留了操作当时的绝对路径。
复用前须核对路径与前置条件，不应直接再次执行迁移脚本。

`snapshots/` 保存当时的代码与测试结果。
后续开发统一修改仓库根目录下的源码。
历史快照不随新修改自动更新。

原项目中的用户数据和恢复备份仍留在原位置。
本次仅整理 Codex 工作区，不移动原项目的图片库。
